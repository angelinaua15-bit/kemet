# Кемет · Kemet

Кінематографічний односторінковий сайт про Стародавній Єгипет. Скрол (або кнопка «▶ Дивитись») програє десять сцен: піраміди Гізи, Сфінкс, Хатшепсут, Нефертіті, маска Тутанхамона, Абу-Сімбел, саркофаг Рамзеса VI, гробниця Нефертарі, суд Осіріса й Розетський камінь.

## Що всередині

- **WebGL-сцени з реальних фото.** Для кожного фото є карта глибини та маска головного об'єкта (`img/*_aux.jpg`, канали R і G) і фон без об'єкта (`img/*_plate.jpg`). Камера рухається з паралаксом, статуї збираються з пікселів і розлітаються золотим пилом.
- **Золотий шар:** промені, пил, плаваючі ієрогліфи, реакція на курсор і швидкість скролу.
- **Дві мови** (українська / English) і **дві теми** (темна / світла, «папірус»).
- **Цифри** з анімованими лічильниками й біжучий рядок фактів.
- **Карусель 11 фараонів** з 3D-нахилом, автопрокруткою й перетягуванням.
- **9 богів** на картках, що перевертаються.
- **Подорож Нілом**: горизонтальна стрічка з 11 місць, яку рухає вертикальний скрол.
- **Сімдесят днів до безсмертя**: етапи муміфікації зі зміною фото.
- **Музей** артефактів із переглядом на весь екран.
- Меню розділів, хронологія, генератор картуша з ієрогліфами, квіз «Іспит писаря» на 10 питань.

## Запуск

Збирати нічого не треба: це один `index.html` і папка `img/` (фото фільму в `img/`, решта в `img/g/`). Відкрий через будь-який статичний сервер, наприклад:

```bash
python3 -m http.server 8000
```

Щоб опублікувати: **Settings → Pages → Deploy from a branch → `main` / root**.
